## Источники расчётов

[Data/resources.json](Catalogs/Data/resources.json) задаёт источники и рецепты; шесть авторских JSON каталогов задают индивидуальные ветви. [expanded_catalog.json](Catalogs/Data/expanded_catalog.json) и файлы Levels — раскрытая ведомость этих данных. Прямые расходы и расшифровка производства слитков хранятся отдельно.

Пересборка и проверки Python3 без внешних библиотек:

```text
python Docs/GameDesign/Model/build_upgrade_catalogs.py
python Docs/GameDesign/Model/check_upgrade_catalogs.py
python Docs/GameDesign/Model/check_economy_paths.py
python Docs/GameDesign/Model/check_plan.py
```

Генератор сохраняет разделы замечаний владельца. Ручное исправление числа в сгенерированной таблице не изменит источник и будет потеряно при следующем экспорте; предложение лучше записать в отведённый раздел, затем после обсуждения перенести в JSON.

Проверки подтверждают арифметику, структуру, ссылки и отдельные экономические инварианты. Сроки прохождения, реальный успех сборок и удержание пока требуют полной событийной и боевой симуляции. Длительный таймер не считается новым содержанием.

## Термины

| Термин | Значение |
|---|---|
| Уровень ветви | Номер покупки конкретного параметра |
| Открытие параметра | Допуск к новой ветви, её числовой бонус начинается с0 |
| Ранг карты | Отдельная покупка за дубликаты определённой карты и кристаллы |
| Тир материала | Глубина доступа к виду сырья,1–6 |
| Сложность биома | Усиленное повторное прохождение уже открытого маршрута |
| Рубеж Gxx | Преграда, требующая достижимой подготовки и победы в бою |
| Базовые минуты печи / слот-дни лаборатории | Объём работы; это не валюта и не фактический календарный срок |
