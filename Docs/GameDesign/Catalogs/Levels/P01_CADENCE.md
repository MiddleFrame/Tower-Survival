# P01_CADENCE — Ритм клика

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **8**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P01; [G01](../../10_ProgressionGates.md#G01)
- Назначение: Умеренная частота действий, без требования частого спама.
- Эффект: Личная ветвь сокращает 0.8 с на 0.02 с за уровень, максимум 0.16 с; итог 0.64 с. [LAB_COOLDOWN](LAB_COOLDOWN.md) действует только на активные и эту пассивку не изменяет.
- Единица результата: секунды сокращения базового CD
- Совместное действие: Карта и лаборатория не уменьшают CD P01. Итоговая частота 1.5625 активаций/с, не зависит от числа касаний сверхлимита.
- Сумма прямых цен: 1 161 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 221 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 1 241 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
