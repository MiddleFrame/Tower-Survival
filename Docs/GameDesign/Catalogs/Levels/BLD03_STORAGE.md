# BLD03_STORAGE — Шахта: склад добытого

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **3**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01); первая ступень MVP
- Назначение: Сократить потери при длинном отсутствии
- Эффект: Склад на 8, 12 и 24 часа вместо 4. Лимит вычисляется для текущего режима участка; уже заработанное не удаляется при смене назначения. Offline боевой фарм регулируется [TW18](TW18.md) отдельно.
- Единица результата: часы накопления шахты
- Совместное действие: Абсолютный предел хранения. Это не дополнительная скорость и не лимит исследования.
- Сумма прямых цен: 38 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 22 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 34 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 12 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU).
- Для производства указанных в цене слитков дополнительно потребуется: 456 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 1 396 [Уголь (COAL)](../08_Resources.md#COAL) + 484 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 088 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 480 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU); 1 сут 13 ч 56 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 5 ч 15 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
