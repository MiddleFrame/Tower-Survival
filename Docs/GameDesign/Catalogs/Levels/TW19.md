# TW19 — Возврат уже заработанной добычи

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: START
- Назначение: Бесплатная гарантия выдачи
- Эффект: Подсказка и восстановление пропущенных подтверждённых наград в итогах забега.
- Единица результата: доступная функция
- Совместное действие: Стоимость0: нельзя продавать возвращение уже начисленного. Это системный контракт, не ветка силы.
- Сумма прямых цен: 0 — бесплатное открытие.
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
