# A08_HASTE — Мощность перегрузки

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **20**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A08; [G03](../../10_ProgressionGates.md#G03)/[L04](../08_Resources.md#L04)
- Назначение: Двадцать малых ступеней временной атаки.
- Эффект: База 35%; личная ветвь+10 п.п., карта+9 п.п.; итог 54%, до общего cap атак.
- Единица результата: процентные пункты к скорости атаки во время эффекта
- Совместное действие: temporaryHasteFraction = (35 + [A08_HASTE](A08_HASTE.md) + [CARD_A08](CARD_A08.md)) / 100; личная ветвь и карта хранят добавочные процентные пункты. Эту долю прибавить один раз к общей доле бонуса скорости атаки. Итоговый интервал атаки не ниже 0.15 с; превью показывает реальный DPS при текущем cap.
- Сумма прямых цен: 11 900 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 33 357 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 33 004 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
