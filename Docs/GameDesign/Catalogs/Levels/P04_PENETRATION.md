# P04_PENETRATION — Глубина прокола

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P04; [G04](../../10_ProgressionGates.md#G04)
- Назначение: Пять редких улучшений роли против брони.
- Эффект: База 40%; итоги 44/48/52/56/60%. Не вычитание 60 п.п. брони; броня 60% при 60% игнорирования становится 24%.
- Единица результата: процент игнорируемой брони цели
- Совместное действие: armorAfterShredPercent = max(0, targetArmorPercent - activeA06ShredPoints), затем effectiveArmorFraction = armorAfterShredPercent / 100 × (1 - [P04_PENETRATION](P04_PENETRATION.md) / 100). [P04_PENETRATION](P04_PENETRATION.md) хранит итоговые 44…60 процентов, не добавку к базовым 40. При отсутствии покупки используется базовое 40. При броне 60%, без A06 и с P04=60% остаётся 0.24, то есть 24% поглощения. Не относится ко всем атакам башни. [TW06](TW06.md) и [LAB_PIERCING](LAB_PIERCING.md) относятся только к выстрелам башни; их величина не добавляется к локальному пробиванию P04.
- Сумма прямых цен: 3 200 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 2 490 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 450 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 5 000 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
