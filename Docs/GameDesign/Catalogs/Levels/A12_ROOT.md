# A12_ROOT — Удержание якоря

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A12; [G05](../../10_ProgressionGates.md#G05)/[L06](../08_Resources.md#L06) доB12
- Назначение: Пять точных ступеней контроля, без общей формулы spellpower.
- Эффект: База 2 с; личная добавка 0.5 с; карта 0.5 с; итог 3 с. Для босса каждая добавка делится на 4: 0.5→0.75 с.
- Единица результата: секунды добавки root обычной цели
- Совместное действие: normalRootSeconds = min(3, 2 + [A12_ROOT](A12_ROOT.md) + [CARD_A12](CARD_A12.md)); bossRootSeconds = normalRootSeconds / 4. Обе ветви хранят добавочные секунды обычной цели, не проценты. [LAB_DURATION](LAB_DURATION.md) исключена; boss interrupt immunity8 с не сокращается.
- Сумма прямых цен: 12 250 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS) + 16 750 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 180 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
