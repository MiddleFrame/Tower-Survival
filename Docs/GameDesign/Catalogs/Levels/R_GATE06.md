# R_GATE06 — Чертёж фокусирующей решётки

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G05](../../10_ProgressionGates.md#G05); [BLD04_L3](BLD04_L3.md); до [G06](../../10_ProgressionGates.md#G06)
- Назначение: Открывает числовую ветвь фокусировки для настройки сборки перед B11.
- Эффект: Открывает [LAB_RESONANT](LAB_RESONANT.md) на уровне 0. Само исследование не усиливает урон, не продлевает окно и не отменяет недосягаемость; результат появится после постепенных покупок [LAB_RESONANT](LAB_RESONANT.md).
- Единица результата: непосредственный числовой бонус: 0; ветвь фокусировки открыта
- Совместное действие: Нет отдельного множителя резонанса. Фокусировка и рикошет выбираются взаимоисключающе вне боя; число изученных ветвей само по себе не усиливает бой.
- Сумма прямых цен: 8 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS) + 12 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 30 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 60 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 240 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU).
- Для производства указанных в цене слитков дополнительно потребуется: 720 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS) + 2 080 [Уголь (COAL)](../08_Resources.md#COAL) + 720 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 960 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 720 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 4 сут 3 ч работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 1 сут при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
