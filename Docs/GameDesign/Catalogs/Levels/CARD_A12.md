# CARD_A12 — Ранг: Якорь

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **9**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: Детерминированная первая копия A12; [BLD06](BLD06.md). Ранг 2 не требует гачи для базовой работоспособности.
- Назначение: Длительная необязательная специализация уже полученной способности.
- Эффект: Покупка 1 повышает ранг 1→2; покупка 9 ранг 9→10. Суммарно+0.5 с к rank10, для босса+0.125 с. Личный+карточный пределroot3 с/0.75 с; generic [LAB_DURATION](LAB_DURATION.md) исключена.
- Единица результата: секунды root обычной цели; для босса четверть
- Совместное действие: [CARD_A12](CARD_A12.md) хранит добавочные 0…0.5 секунды root обычной цели. normalRootSeconds = min(3, 2 + [A12_ROOT](A12_ROOT.md) + [CARD_A12](CARD_A12.md)); боссу normalRootSeconds/4. Лабораторная длительность исключена; interrupt immunity8 с, заряды и слоты не меняются.
- Сумма прямых цен: 1 022 [Дубликат A12 (CARD_A12)](../08_Resources.md#CARD_A12) + 51 970 [Кристаллы (CRYSTAL)](../08_Resources.md#CRYSTAL).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
