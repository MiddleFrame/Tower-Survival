# P02_BOUNTY — Точность добычи

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **12**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P02; первая победа; [G01](../../10_ProgressionGates.md#G01)
- Назначение: Доход ценой отказа от боевой пассивной.
- Эффект: База +20%; личная ветвь добавляет максимум +6 п.п. Карта добавляет до +2.25 п.п.
- Единица результата: процентные пункты к обычному количеству сырья/угля
- Совместное действие: markBonusPercent = 20 + [P02_BOUNTY](P02_BOUNTY.md) + [CARD_P02](CARD_P02.md): два улучшения хранят процентные пункты. activeResonancePercent = 15 + [A02_YIELD](A02_YIELD.md), только пока A02 действует. Для каждого материала rewardMultiplier = 1 + min(35, otherMaterialLootBonusPercent + markBonusPercent + activeResonancePercent) / 100; неактивный эффект даёт 0. В otherMaterialLootBonusPercent входят допустимые бонусы башни и лаборатории этого ресурса. Кристаллы/слитки/first-clear и призванные без наград цели исключены; один proc на естественную смерть.
- Сумма прямых цен: 1 342 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 3 522 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 2 441 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 3 101 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
