# TW07 — Дополнительные цели

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02) + Арканум
- Назначение: Сильный дискретный скачок против групп
- Эффект: Общее число целей одного выстрела: 2 затем 3. Дополнительная цель получает 50% исходного урона; по одиночному боссу бонуса нет.
- Единица результата: целей
- Совместное действие: Бюджет максимального суммарного урона ×1.5/×2 при наличии целей, без рекурсивного proc; [BLD01_MODULE](BLD01_MODULE.md) открывает отдельный режим залпа, повторно эту цель не покупает.
- Сумма прямых цен: 35 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 45 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 90 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 140 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 1 120 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 6 350 [Уголь (COAL)](../08_Resources.md#COAL) + 540 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 5 400 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 3 080 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 11 сут 15 ч 40 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
