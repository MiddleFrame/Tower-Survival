# BLD03_COAL — Шахта: угольный штрек

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **10**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01); первая ступень MVP
- Назначение: Опциональный ответ на топливный дефицит без блокировки угольного режима
- Эффект: Накопительный бонус добычи угля на участке +5%…+50%. Угольный режим существует до покупки; не требует угля, который сам должен открыть.
- Единица результата: накопительные процентные пункты скорости угля
- Совместное действие: Коэффициент 1 + [BLD03_COAL](BLD03_COAL.md)/100; не умножает добычу руды и не создаёт параллельный угольный поток.
- Сумма прямых цен: 164 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 67 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 17 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 63 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 24 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY).
- Для производства указанных в цене слитков дополнительно потребуется: 1 968 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 4 804 [Уголь (COAL)](../08_Resources.md#COAL) + 1 474 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 544 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 2 520 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 1 440 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY); 6 сут 19 ч 32 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 1 сут 11 ч 25 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
