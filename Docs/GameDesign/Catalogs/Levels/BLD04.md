# BLD04 — Лаборатория: первый корпус

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01); MVP
- Назначение: Доступ к дешёвым первым исследованиям и обязательному [R_GATE02](R_GATE02.md)
- Эффект: Один исследовательский слот, скорость ×1, учебное исследование и отдельная обязательная технология доступны по своим ценам. Корпус не выдаёт [R_GATE02](R_GATE02.md) бесплатно.
- Единица результата: доступ: 0 или 1
- Совместное действие: Однократный доступ; [R_GATE02](R_GATE02.md) оплачивается только в каталоге лаборатории.
- Сумма прямых цен: 20 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 10 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 240 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 220 [Уголь (COAL)](../08_Resources.md#COAL) + 220 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 4 ч 20 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 30 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.

[Вернуться к каталогу](../00_Index.md). Табличный результат накопительный, не ещё одна прибавка за каждый предыдущий уровень.
