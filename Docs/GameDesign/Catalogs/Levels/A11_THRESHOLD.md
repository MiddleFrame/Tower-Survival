# A11_THRESHOLD — Уверенное завершение

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A11; [G05](../../10_ProgressionGates.md#G05)
- Назначение: Два дорогих свойства, меняющих момент применения.
- Эффект: База 25%→27.5%→30%. Боссовый 5%damagecap неизменен.
- Единица результата: процент HP, ниже которого доступен 7D
- Совместное действие: Ветвь хранит итоговый порог 27.5/30 процентовHP, уже включая базовый 25. Условие усиленного удара: currentHP / maxHP < thresholdPercent / 100. При отсутствии покупки thresholdPercent=25. Боссовый предел 5% исходногоHP остаётся отдельным ограничением.
- Сумма прямых цен: 125 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS) + 215 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 400 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 11 250 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS) + 23 675 [Уголь (COAL)](../08_Resources.md#COAL) + 12 900 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 8 800 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 57 сут 12 ч 50 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
