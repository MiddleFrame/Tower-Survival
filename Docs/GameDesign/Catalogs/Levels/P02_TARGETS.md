# P02_TARGETS — Несколько меток

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P02; [G01](../../10_ProgressionGates.md#G01)
- Назначение: Отдельные редкие функциональные покупки.
- Эффект: Базовые 3; первая покупка 4, вторая 5.
- Единица результата: число одновременно помеченных целей
- Совместное действие: Больше целей не увеличивает награду одной цели; общий loot cap сохраняется.
- Сумма прямых цен: 32 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 18 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 12 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 704 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 716 [Уголь (COAL)](../08_Resources.md#COAL) + 576 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 144 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 17 ч 40 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
