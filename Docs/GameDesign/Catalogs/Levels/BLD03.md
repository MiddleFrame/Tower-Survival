# BLD03 — Шахта: первый участок

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01) / B01 tier1; MVP
- Назначение: Постоянный независимый источник открытой руды или угля
- Эффект: Один участок, склад на 4 часа. База за час выбранного режима: CU 60; FE 42; AG 28; AU 18; MY 10; AS 6; уголь 35. Участок работает только в одном режиме. Закрытые ресурсы недоступны.
- Единица результата: участки
- Совместное действие: Базовое состояние; скорости разных руд не взаимозаменяемы.
- Сумма прямых цен: 8 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 96 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 48 [Уголь (COAL)](../08_Resources.md#COAL); 48 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 10 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
