# BLD12_CONSTRUCTION — Ратуша: вторая строительная очередь

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G04](../../10_ProgressionGates.md#G04) + глава мастерства 12; версия 1.0
- Назначение: Параллельная стройка без эксклюзивного платного доступа
- Эффект: Даёт всего две строительные очереди вместо одной. Одна постройка не может строить два последовательных уровня одновременно. Ресурсы каждого задания списываются отдельно.
- Единица результата: строительные очереди
- Совместное действие: Абсолютный предел 2; не множитель таймера отдельной стройки.
- Сумма прямых цен: 60 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 20 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 80 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 50 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 2 400 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 3 560 [Уголь (COAL)](../08_Resources.md#COAL) + 1 200 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 960 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 1 100 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 5 сут 9 ч 40 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 1 сут при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
