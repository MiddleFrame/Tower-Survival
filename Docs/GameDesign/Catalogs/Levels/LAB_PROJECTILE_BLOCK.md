# LAB_PROJECTILE_BLOCK — Противоснарядная сетка

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **15**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G04](../../10_ProgressionGates.md#G04); [BLD04_L2](BLD04_L2.md)
- Назначение: Особая защитная специализация против стрелков.
- Эффект: До 15% вероятности блокировать обычный вражеский снаряд; лучи, контакт и отмеченные атаки боссов не блокируются.
- Единица результата: проценты шанса блока обычного снаряда
- Совместное действие: В общий предел вероятности блока 30%; блок считается один раз и не отражает заблокированный урон.
- Сумма прямых цен: 2 050 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 77 600 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 8 250 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 61 250 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 28 000 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 16 500 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Сумма работы этой последовательной ветки: 51 сут 23 ч 30 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
