# P03_RADIUS — Охват импульса

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **6**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P03; [G02](../../10_ProgressionGates.md#G02)
- Назначение: Увеличивает реальную область, но не предел целей.
- Эффект: База 0.45R; личная ветвь до 0.573R. [LAB_AREA](LAB_AREA.md) добавляет максимум 0.027R (6% базы); совместный предел 0.60R.
- Единица результата: доля R; итоговый радиус
- Совместное действие: Итоговый radiusInR = min(0.60, ownRadiusInR + 0.45 × [LAB_AREA](LAB_AREA.md) / 100). Личная ветвь уже хранит итоговый радиус в долях R; [LAB_AREA](LAB_AREA.md) хранит 0…6 процентов базового радиуса. Не умножать личный радиус на 1.06; карта радиус не изменяет. Число целей задаётся отдельной ветвью.
- Сумма прямых цен: 1 215 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 3 570 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 2 025 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
