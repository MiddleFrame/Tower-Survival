# R_GATE02 — Чертёж бронебойного снаряда

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01); [BLD04](BLD04.md); до [G02](../../10_ProgressionGates.md#G02)
- Назначение: Открывает ось пробивания для дальнейшей постепенной подготовки к B02.
- Эффект: Открывает покупку [TW06](TW06.md) и [LAB_PIERCING](LAB_PIERCING.md). Само исследование даёт 0 п.п. пробивания и не меняет DPS; после открытия обе ветви имеют уровень 0.
- Единица результата: непосредственный числовой бонус: 0; право покупки ветвей открыто
- Совместное действие: Пробивание появляется только от оплаченных числовых уровней [TW06](TW06.md) и [LAB_PIERCING](LAB_PIERCING.md). Для выстрела: поглощение=max(0, базовое поглощение−[TW06](TW06.md)−[LAB_PIERCING](LAB_PIERCING.md)/100). Нельзя дополнительно применять множитель 1,65; M06 и неуязвимость не снимаются.
- Сумма прямых цен: 4 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 3 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 40 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 60 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 48 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 54 [Уголь (COAL)](../08_Resources.md#COAL) + 66 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 1 ч 6 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 3 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
