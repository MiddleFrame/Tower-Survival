# BLD11 — Арена

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03) + 3 контрсборки + готова сетевая инфраструктура; версия 1.0
- Назначение: Сравнение тактических результатов при нормализованной силе
- Эффект: Доступ к daily endless, рейтингу, нормализации и серверной проверке награды. Готовность инфраструктуры — условие выпуска функции, никогда не цена для игрока. Нет платного усиления рейтинговой сборки через здание.
- Единица результата: доступ: 0 или 1
- Совместное действие: Одна постройка; антимошенничество, восстановление наград и нормализация бесплатны.
- Сумма прямых цен: 20 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 8 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 18 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 640 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 764 [Уголь (COAL)](../08_Resources.md#COAL) + 320 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 396 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 22 ч 12 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 4 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
