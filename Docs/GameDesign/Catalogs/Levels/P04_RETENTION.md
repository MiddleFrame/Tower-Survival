# P04_RETENTION — Память руны

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P04; [G04](../../10_ProgressionGates.md#G04)
- Назначение: Новый способ планировать клики; не добавляет урон сам по себе.
- Эффект: При смене цели сохраняет счётчик только прежней цели 0.5/1 с; новые попадания по другой цели начинают её счётчик с нуля. Хранится максимум одна старая цель.
- Единица результата: секунды хранения счётчика прежней цели
- Совместное действие: Не суммируется с generic [LAB_DURATION](LAB_DURATION.md); смерть/исчезновение цели удаляет запись.
- Сумма прямых цен: 74 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 40 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 102 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 22 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 4 440 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 7 230 [Уголь (COAL)](../08_Resources.md#COAL) + 1 600 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 2 244 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 980 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 15 сут 20 ч 48 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
