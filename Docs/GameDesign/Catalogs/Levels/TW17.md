# TW17 — Радиус подбора

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **10**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01)
- Назначение: Удобство, без роста выдачи
- Эффект: Радиус взаимодействия с drop +2.5% за шаг, до+25%.
- Единица результата: множитель радиуса подбора
- Совместное действие: Текущая ветка даёт до ×1.25; общий резервный предел ×1.5 для будущих явно назначенных эффектов. В текущем лабораторном каталоге дополнительного радиуса подбора нет. Пропущенные заработанные награды возвращаются бесплатно через [TW19](TW19.md).
- Сумма прямых цен: 1 676 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 300 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 1 050 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
