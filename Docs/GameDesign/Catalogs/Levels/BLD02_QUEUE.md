# BLD02_QUEUE — Кузница: длина очереди

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **4**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G01](../../10_ProgressionGates.md#G01); MVP допускает первую покупку
- Назначение: Автономность между возвращениями
- Эффект: Лимит будущей работы на одну печь растёт с 30 минут до 2, 8, 12 и 24 часов. Это реальная длительность при текущей скорости. Уже оплаченный заказ не отбрасывается при изменении скорости. Одна единица открытого рецепта разрешена, даже если её время больше лимита очереди.
- Единица результата: минуты автономной работы на печь
- Совместное действие: Абсолютный предел: 120 / 480 / 720 / 1440 минут; не производственный множитель.
- Сумма прямых цен: 86 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 22 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 30 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 8 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 24 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 8 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 1 032 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 3 220 [Уголь (COAL)](../08_Resources.md#COAL) + 484 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 960 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 320 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 1 440 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 720 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 6 сут 44 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 14 ч 55 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
