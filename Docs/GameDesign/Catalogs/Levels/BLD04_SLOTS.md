# BLD04_SLOTS — Лаборатория: исследовательские места

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); после MVP
- Назначение: Очень сильное ускорение параллельного освоения разных ветвей
- Эффект: Пять покупок дают всего 2…6 одновременно работающих исследовательских слотов. Нельзя исследовать два уровня одной последовательной ветки одновременно. Новый слот не ускоряет уже идущий job.
- Единица результата: одновременные исследовательские слоты
- Совместное действие: Абсолютное число слотов, максимум 6. Это иной объект, чем [LAB_SLOTS](LAB_SLOTS.md) активных заклинаний.
- Сумма прямых цен: 2 336 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 1 264 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 68 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 160 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 1 540 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 700 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 28 032 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 157 660 [Уголь (COAL)](../08_Resources.md#COAL) + 27 808 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 2 176 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 6 400 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 92 400 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 63 000 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 365 сут 12 ч 32 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 6 сут 14 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
