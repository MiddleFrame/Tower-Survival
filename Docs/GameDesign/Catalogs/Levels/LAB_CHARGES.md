# LAB_CHARGES — Запасной рунический контейнер

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); [BLD04](BLD04.md); [BLD06](BLD06.md)
- Назначение: Открывает доступ к личным ступеням запаса активных заклинаний без собственной выдачи зарядов.
- Эффект: Исследование 1 разрешает покупку первой личной ступени Axx_CHARGES, исследование 2 — второй. Ни одно исследование само не добавляет заряда; после допуска нужно отдельно оплатить соответствующую ветвь выбранной способности.
- Единица результата: непосредственные дополнительные заряды: 0; ступень допуска указана номером исследования
- Совместное действие: Единственный числовой источник дополнительных зарядов — личные Axx_CHARGES. Их общий предел +2 на способность сохраняется; лабораторного добавочного слагаемого больше нет. Доступ не открывает несуществующую ветвь у способности без Axx_CHARGES.
- Сумма прямых цен: 8 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 52 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 60 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 12 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 24 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 400 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 176 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 364 [Уголь (COAL)](../08_Resources.md#COAL) + 624 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 720 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 768 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG); 2 сут 1 ч 4 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 2 сут 6 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
