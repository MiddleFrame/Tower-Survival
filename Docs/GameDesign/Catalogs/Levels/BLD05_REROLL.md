# BLD05_REROLL — Гильдия: дополнительные бесплатные перебросы

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03); версия 1.0
- Назначение: Меньше неподходящих целей, без покупки награды
- Эффект: Суммарно два, затем три бесплатных переброса обычного daily в сутки вместо одного. Не обновляет уже полученные награды, сезонный бюджет и гарантированный обязательный контрпредмет.
- Единица результата: бесплатные перебросы в сутки
- Совместное действие: Абсолютное число 2 / 3; переброс не должен давать второй набор оплаченных daily.
- Сумма прямых цен: 18 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 51 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 15 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 32 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE).
- Для производства указанных в цене слитков дополнительно потребуется: 576 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 2 747 [Уголь (COAL)](../08_Resources.md#COAL) + 2 040 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 900 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 704 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE); 4 сут 8 ч 58 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 8 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
