# BLD03_PLOTS — Шахта: дополнительные участки

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); после MVP
- Назначение: Одновременно снабжать кузницу топливом и конкретной рудой
- Эффект: Первое улучшение даёт всего 2 участка, второе — 3. Каждый имеет отдельный выбранный режим; склады общие по ресурсному ID с одинаковым временным лимитом.
- Единица результата: участки
- Совместное действие: Абсолютное число 2 / 3; не умножать добычу одного участка на число выбранных ресурсов.
- Сумма прямых цен: 24 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 60 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 51 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 20 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 8 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY).
- Для производства указанных в цене слитков дополнительно потребуется: 288 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 2 582 [Уголь (COAL)](../08_Resources.md#COAL) + 1 320 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 632 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 800 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 480 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY); 3 сут 9 ч 54 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 14 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
