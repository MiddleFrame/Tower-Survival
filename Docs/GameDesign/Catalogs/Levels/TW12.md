# TW12 — Ответный урон

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **20**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02)
- Назначение: Ситуационная ветка, не заменяет основной выстрел
- Эффект: Возвращает 0.5% принятого прямого урона за шаг, до 10%.
- Единица результата: доля принятого урона
- Совместное действие: Итоговый reflect ≤20%; отражение не порождает отражение и не лечит башню. Рассчитывать по фактически принятому урону.
- Сумма прямых цен: 1 354 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 2 204 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 8 403 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 26 500 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
