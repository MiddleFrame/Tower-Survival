# A10_CAPACITY — Плотность перехвата

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **4**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A10; [G04](../../10_ProgressionGates.md#G04)/[L05](../08_Resources.md#L05) доB09
- Назначение: Четыре дискретные структурные ступени.
- Эффект: База 12→14→16→18→20.
- Единица результата: количество перехватов обычных снарядов за cast
- Совместное действие: Один снаряд списывается один раз; тяжёлые телеграфированные снаряды не удаляются и не превращаются в обычные.
- Сумма прямых цен: 181 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 249 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 79 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 10 860 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 16 955 [Уголь (COAL)](../08_Resources.md#COAL) + 5 478 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 7 110 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 41 сут 36 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
