# A10_MITIGATION — Рассеивание тяжёлого удара

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **10**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A10; [G04](../../10_ProgressionGates.md#G04)
- Назначение: Десять небольших ступеней специальной защиты.
- Эффект: База 40%; личная ветвь+10 п.п.; карта+9 п.п.; итог 59%, специальный cap60%.
- Единица результата: процентные пункты снижения урона тяжёлых снарядов
- Совместное действие: heavyReductionFraction = min(60, 40 + [A10_MITIGATION](A10_MITIGATION.md) + [CARD_A10](CARD_A10.md)) / 100; личная ветвь и карта хранят добавочные процентные пункты. Урон тяжёлого снаряда после этой защиты = входящийУрон × (1 - heavyReductionFraction). Другие типы защиты учитываются отдельно в EHP; эта формула не означает постоянного снижения всех источников.
- Сумма прямых цен: 6 400 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 25 700 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 676 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 19 750 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
