Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **20**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: START
- Назначение: Раннее удобство, затем тактическая ценность
- Эффект: Радиус относительно исходного. Ранние шаги +1%, поздние +0.5%; boss вне досягаемости не обязан становиться доступным этой веткой.
- Единица результата: множитель радиуса
- Совместное действие: С лабораторией и временными эффектами не выше ×1.5; эта ветка занимает только +15%.
- Сумма прямых цен: 628 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 3 750 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 1 904 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
