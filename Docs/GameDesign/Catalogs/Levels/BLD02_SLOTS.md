# BLD02_SLOTS — Кузница: дополнительные печи

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **3**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); после MVP
- Назначение: Сильные скачки общей мощности и параллельная работа с разными рудами
- Эффект: Покупки дают всего 2, 3 и 4 одновременно работающие печи. Число печей не меняет скорость отдельного заказа и требует отдельного топлива для каждой.
- Единица результата: одновременные печи
- Совместное действие: Заменяет общий предел 1 → 2 → 3 → 4; не прибавлять каждое значение.
- Сумма прямых цен: 88 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 136 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 52 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 140 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 80 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 24 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 1 056 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 12 264 [Уголь (COAL)](../08_Resources.md#COAL) + 2 992 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 664 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 5 600 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 4 800 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 2 160 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 22 сут 22 ч 32 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 3 сут 14 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
