# A06_SHRED — Глубина разлома

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A06; [G02](../../10_ProgressionGates.md#G02)
- Назначение: Пять дорогих улучшений тактической роли.
- Эффект: База 30 п.п.; итог 32/34/36/38/40 п.п.; итоговая броня не ниже 0.
- Единица результата: процентные пункты снимаемой брони
- Совместное действие: Ветвь хранит итоговые 32…40 процентных пунктов снятия, с уже включённой базой 30. armorAfterShredPercent = max(0, targetArmorPercent - [A06_SHRED](A06_SHRED.md)); без покупки используется 30. Повторный A06 обновляет срок, не суммирует снятие. P04 затем умножает остаток на(1 - [P04_PENETRATION](P04_PENETRATION.md) / 100).
- Сумма прямых цен: 720 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 4 080 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 720 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 2 450 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 3 200 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
