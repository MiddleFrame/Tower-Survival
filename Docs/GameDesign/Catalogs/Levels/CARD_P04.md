# CARD_P04 — Ранг: Рунический прокол

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **9**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: Детерминированная первая копия P04; [BLD06](BLD06.md). Ранг 2 не требует гачи для базовой работоспособности.
- Назначение: Длительная необязательная специализация уже полученной способности.
- Эффект: Покупка 1 повышает ранг 1→2; покупка 9 ранг 9→10. +8 п.п. базового урона за ранг, без роста penetration/частоты третьего удара.
- Единица результата: аддитивная доля базового урона
- Совместное действие: Значение личной ветви — множитель с уже включённой единицей; cardFraction берётся прямо из CARD_ID как доля 0…0.72. labFraction = min(0.28, [LAB_SPELL_POWER](LAB_SPELL_POWER.md) / 100 + selectedProtocolBonusPercent / 100): [LAB_SPELL_POWER](LAB_SPELL_POWER.md) хранит 0…16 процентов, выбранный допустимый протокол даёт 0…12 процентов. [LAB_INTERACTION](LAB_INTERACTION.md) хранит число открытых протоколов, не процент бонуса. Множитель урона = min(3, ownMultiplier + cardFraction + labFraction). Карта хранит долю напрямую:0.08 означает+8 п.п. базового урона; делить её ещё раз на 100 нельзя. Не даёт слоты или заряды.
- Сумма прямых цен: 1 022 [Дубликат P04 (CARD_P04)](../08_Resources.md#CARD_P04) + 48 170 [Кристаллы (CRYSTAL)](../08_Resources.md#CRYSTAL).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
