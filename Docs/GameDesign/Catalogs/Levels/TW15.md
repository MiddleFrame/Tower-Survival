# TW15 — Добыча сырья

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **20**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: START
- Назначение: Небольшое хозяйственное решение с окупаемостью
- Эффект: +0.5% количества обычной руды за шаг до+10%, для каждого исходного вида отдельно.
- Единица результата: доля дополнительной руды
- Совместное действие: Внутри общего combat economy cap35%; не увеличивает уголь, кристаллы, слитки, first-clear или спавн. При max окупаемость считать в конкретном маршруте.
- Сумма прямых цен: 8 514 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 2 050 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 2 876 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 14 250 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
