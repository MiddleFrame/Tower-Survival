# LAB_DURATION — Удержание безопасных эффектов

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **30**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03); [BLD04](BLD04.md)
- Назначение: Помогает длительным защитным и уронным эффектам без бесконечного контроля.
- Эффект: До +10% базовой длительности только A01/A02/A04/A05/A06/A08/A10. Для A01 это ровно +0,4 секунды к базовым 4 секундам: с личными +30% и карточными +10% итог не выше 6 секунд. A12 с жёстким контролем, лечение A09 и все прочие эффекты вне этого списка лабораторный бонус длительности не получают.
- Единица результата: проценты длительности разрешённого эффекта
- Совместное действие: Складывается с указанной общей осью; не перемножать с каждым уровнем. Значение строки — весь накопленный бонус этой ветви. Общий множитель длительности допустимых эффектов ≤1,5.
- Сумма прямых цен: 64 607 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 115 757 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 16 504 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 36 004 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 30 004 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY).
- Готовые материалы в прямой цене этой ветки не требуются.
- Сумма работы этой последовательной ветки: 51 сут 23 ч 33 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
