# A10_DURATION — Стойкость завесы

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **8**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A10; [G04](../../10_ProgressionGates.md#G04)
- Назначение: Продолжительность полезна лишь пока есть запас перехвата.
- Эффект: Личная ветвь+2 с; [LAB_DURATION](LAB_DURATION.md) при 10% даёт+0.5 с; карта длительность не меняет; итог 7.5 с.
- Единица результата: секунды добавки к 5 с
- Совместное действие: durationSeconds = min(5 × 1.5, 5 + ownAddedSeconds + 0 + 5 × [LAB_DURATION](LAB_DURATION.md) / 100). Личная добавка и указанная duration-карта хранят секунды; [LAB_DURATION](LAB_DURATION.md) хранит 0…10 процентов базовых 5 с. Карта этой способности длительность не меняет. Проверять только разрешённый эффект, не распространять формулу на лечение/урон/число целей.
- Сумма прямых цен: 2 301 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 19 861 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 11 401 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS) + 2 601 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
