# BLD10 — Обсерватория

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02) + 10 постоянных испытаний; версия 1.0
- Назначение: Еженедельные задачи с заранее видимыми условиями
- Эффект: Пять испытаний по пять одноразовых этапов в неделю. Предпросмотр модификаторов, правила наград, расписание и история выдачи включены в здание.
- Единица результата: доступ: 0 или 1
- Совместное действие: Одна постройка; прогноз угроз не делится на фиктивные уровни исследования.
- Сумма прямых цен: 24 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 12 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG).
- Для производства указанных в цене слитков дополнительно потребуется: 528 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 456 [Уголь (COAL)](../08_Resources.md#COAL) + 384 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG); 11 ч 36 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 2 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
