# A03_RADIUS — Ширина удара

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **10**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A03; [G01](../../10_ProgressionGates.md#G01)
- Назначение: Расширяет выбор точки, без роста лимита целей.
- Эффект: База 0.35R; личная ветвь до 0.429R. [LAB_AREA](LAB_AREA.md) добавляет до 0.021R (6% базы); совместный предел 0.45R.
- Единица результата: доля R; итоговый радиус
- Совместное действие: Итоговый radiusInR = min(0.45, ownRadiusInR + 0.35 × [LAB_AREA](LAB_AREA.md) / 100). Личная ветвь уже хранит итоговый радиус в долях R; [LAB_AREA](LAB_AREA.md) хранит 0…6 процентов базового радиуса. Не умножать личный радиус на 1.06; карта радиус не изменяет. Число целей задаётся отдельной ветвью.
- Сумма прямых цен: 3 226 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 4 940 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 5 126 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
