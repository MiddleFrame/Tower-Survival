# A01_DURATION — Плотность купола

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A01; учебная награда
- Назначение: Пять небольших ступеней внутри общего окна защиты.
- Эффект: Личная добавка 1.2 с; [LAB_DURATION](LAB_DURATION.md) при 10% даёт 0.4 с; карта 0.4 с; максимум 6 с.
- Единица результата: секунды добавки к 4 с
- Совместное действие: durationSeconds = min(4 × 1.5, 4 + ownAddedSeconds + [CARD_A01](CARD_A01.md) + 4 × [LAB_DURATION](LAB_DURATION.md) / 100). Личная добавка и указанная duration-карта хранят секунды; [LAB_DURATION](LAB_DURATION.md) хранит 0…10 процентов базовых 4 с. Проверять только разрешённый эффект, не распространять формулу на лечение/урон/число целей.
- Сумма прямых цен: 750 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 1 800 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 980 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 650 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 1 500 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
