# LAB_COOLDOWN — Быстрое связывание рун

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **25**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03); [BLD04](BLD04.md)
- Назначение: Умеренно уплотняет расход конечных зарядов, не восстанавливая их.
- Эффект: До 10% сокращения интервала между применениями только активных заклинаний. Пассивные кликовые P01–P04 не получают этот лабораторный бонус.
- Единица результата: проценты сокращения базового cooldown
- Совместное действие: Суммируется с личной веткой до общего сокращения 40%; итоговый cooldown ≥60% базы.
- Сумма прямых цен: 149 408 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 122 203 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 37 004 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 132 500 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 28 500 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Сумма работы этой последовательной ветки: 105 сут 22 ч 33 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
