# LAB_SLOTS — Дополнительная печать заклинания

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); [BLD04](BLD04.md); [BLD06](BLD06.md)
- Назначение: Один из главных игровых переломов: больше одновременно взятых активных способностей.
- Эффект: Начальный один активный слот становится двумя после уровня 1 и тремя после уровня 2. Количество пассивных слотов остаётся 1.
- Единица результата: общее число активных слотов после исследования
- Совместное действие: Единственный владелец активных слотов. Арканум, карты, герои и другие исследования не продают эти же два слота повторно.
- Сумма прямых цен: 30 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 12 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 80 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 40 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS) + 100 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 660 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 7 916 [Уголь (COAL)](../08_Resources.md#COAL) + 384 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 4 800 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 3 600 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS) + 1 200 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 19 сут 7 ч работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 31 сут при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
