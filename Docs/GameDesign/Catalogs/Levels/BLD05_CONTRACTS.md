# BLD05_CONTRACTS — Гильдия: длительные контракты

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **2**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); после MVP
- Назначение: Самостоятельные цели на несколько посещений
- Эффект: Первая покупка открывает один параллельный контракт, вторая — два. Контракт занимает 12–24 реальных часа и требует явно указанной задачи; само ожидание без условия не создаёт награду. Базовые 3 daily остаются отдельно.
- Единица результата: одновременно активные длительные контракты
- Совместное действие: Абсолютное число 1 / 2; не дополнительные случайные daily.
- Сумма прямых цен: 66 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 6 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 60 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 24 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY).
- Для производства указанных в цене слитков дополнительно потребуется: 1 452 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 3 528 [Уголь (COAL)](../08_Resources.md#COAL) + 192 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 2 400 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 1 440 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY); 5 сут 18 ч 24 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 13 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
