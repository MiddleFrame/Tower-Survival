# LAB_COAL_EFFICIENCY — Закрытый топливный цикл

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **20**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); [BLD04](BLD04.md)
- Назначение: Снижает только топливную нагрузку, особенно заметно на дорогих материалах.
- Эффект: До 10% сокращения [Уголь (COAL)](../08_Resources.md#COAL) будущего рецепта; расход сырья и время не изменяются.
- Единица результата: проценты сокращения угля рецепта
- Совместное действие: Для допустимой партии n слитков: ceil(n × базовый уголь × (1−бонус/100)); минимум n. Целочисленное округление применяется к партии. UI показывает фактическую экономию; слишком маленькая партия может экономить 0 единиц. Разделение партии не увеличивает скидку. Изменение исследования после запуска не пересчитывает оплаченный заказ.
- Сумма прямых цен: 2 600 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 95 855 [Уголь (COAL)](../08_Resources.md#COAL) + 111 953 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 15 750 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 104 000 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS).
- Готовые материалы в прямой цене этой ветки не требуются.
- Сумма работы этой последовательной ветки: 109 сут 11 ч 33 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
