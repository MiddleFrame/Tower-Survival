# A08_DURATION — Выдержка перегрузки

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **8**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A08; [G03](../../10_ProgressionGates.md#G03)
- Назначение: Восемь небольших прибавок длины окна.
- Эффект: Личный максимум 3.2 с; лаборатория 0.8 с; карта длительность не меняет; итог 12 с.
- Единица результата: секунды добавки к 8 с
- Совместное действие: durationSeconds = min(8 × 1.5, 8 + ownAddedSeconds + 0 + 8 × [LAB_DURATION](LAB_DURATION.md) / 100). Личная добавка и указанная duration-карта хранят секунды; [LAB_DURATION](LAB_DURATION.md) хранит 0…10 процентов базовых 8 с. Карта этой способности длительность не меняет. Проверять только разрешённый эффект, не распространять формулу на лечение/урон/число целей.
- Сумма прямых цен: 2 120 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 11 821 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 8 601 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 1 700 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
