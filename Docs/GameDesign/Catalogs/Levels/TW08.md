# TW08 — Приоритет цели

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03) + глава мастерства 6
- Назначение: Функциональный выбор, один уровень
- Эффект: Разрешает ручной выбор правила башни: ближайший / дальний / максимум здоровья. Это боевой эффект автоматики, а не плата за интерфейс подсказок.
- Единица результата: набор правил
- Совместное действие: Один выбранный приоритет, не три одновременно; не даёт башне достать внешнего босса.
- Сумма прямых цен: 20 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 35 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 800 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 770 [Уголь (COAL)](../08_Resources.md#COAL) + 420 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 23 ч 30 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
