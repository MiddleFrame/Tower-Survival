# BLD08 — Таверна

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02) + завершено обучение наградам; после MVP
- Назначение: Единое окно рекламного обмена
- Эффект: Четыре ежедневных предложения и постоянный обмен. Нет платных уровней, увеличивающих обязательный просмотр рекламы. Условия no-ads и цены товаров хранятся в монетизации, не в цене здания.
- Единица результата: доступ: 0 или 1
- Совместное действие: Одна постройка; обновление витрины и проверка покупок не отдельные улучшения.
- Сумма прямых цен: 16 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 8 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG).
- Для производства указанных в цене слитков дополнительно потребуется: 352 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 304 [Уголь (COAL)](../08_Resources.md#COAL) + 256 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG); 7 ч 44 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 1 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
