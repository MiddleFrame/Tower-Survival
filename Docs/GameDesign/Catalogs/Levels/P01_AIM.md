# P01_AIM — Помощь прицеливания

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **6**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: P01; старт
- Назначение: Удобство касания без прироста силы по одной цели.
- Эффект: Базовая зона помощи 0.10R; до 0.16R. Не расширяет боевую дальность и не пробивает UI.
- Единица результата: доля R; итоговый радиус помощи
- Совместное действие: Эффект указан накопительно; не умножать повторно другими ветвями.
- Сумма прямых цен: 390 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 405 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
