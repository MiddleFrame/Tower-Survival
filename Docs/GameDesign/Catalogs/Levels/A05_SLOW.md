# A05_SLOW — Плотность стужи

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **5**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A05; [G02](../../10_ProgressionGates.md#G02)/[L03](../08_Resources.md#L03)
- Назначение: Пять небольших ступеней против быстрых врагов.
- Эффект: База 45%→50%; босс остаётся 20%, без наследования этого бонуса.
- Единица результата: процентные пункты замедления обычных целей
- Совместное действие: normalSlowFraction = (45 + [A05_SLOW](A05_SLOW.md)) / 100: [A05_SLOW](A05_SLOW.md) хранит только добавочные 1…5 процентных пунктов; bossSlowFraction = 20 / 100. Несколько slow не перемножаются: применяется самое сильное разрешённое значение.
- Сумма прямых цен: 2 040 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 1 135 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE).
- Готовые материалы в прямой цене этой ветки не требуются.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
