# BLD12 — Ратуша

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **1**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G03](../../10_ProgressionGates.md#G03) + глава мастерства 6; версия 1.0
- Назначение: Управление доктриной и структурными главами прогрессии
- Эффект: Открывает управление главами мастерства и первую доктрину. Смена доступной доктрины и 3 пресета бесплатны вне боя. Главы не взимают повторную цену за уже купленные конкретные улучшения.
- Единица результата: доступ: 0 или 1
- Совместное действие: Одна постройка; численные эффекты доктрин описаны у башни.
- Сумма прямых цен: 30 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 12 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 28 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 960 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 1 044 [Уголь (COAL)](../08_Resources.md#COAL) + 480 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 336 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 1 сут 5 ч 48 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 6 ч при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
