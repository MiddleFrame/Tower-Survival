# LAB_RECOVERY — Ремонт между волнами

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **30**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); [BLD04](BLD04.md)
- Назначение: Восстановление в паузе поддерживает длинный забег, но не решает burst-порог.
- Эффект: По завершении боевой волны восстанавливает до 3% максимального HP. Требует настоящего перехода волны; не срабатывает на перезапуск сохранения.
- Единица результата: проценты максимального здоровья за завершённую волну
- Совместное действие: Суммируется до общего предела лечения между волнами 10% HP; не действует внутри бесконечной волны рейтинга.
- Сумма прямых цен: 75 600 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 20 307 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 7 004 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 18 504 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 28 004 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU).
- Готовые материалы в прямой цене этой ветки не требуются.
- Сумма работы этой последовательной ветки: 23 сут 11 ч 48 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
