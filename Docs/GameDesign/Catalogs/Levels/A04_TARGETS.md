# A04_TARGETS — Широкое рассеивание

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **3**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: A04; [G01](../../10_ProgressionGates.md#G01)
- Назначение: Каждая ступень расширяет выбор, не стирает все виды защиты.
- Эффект: База 5→6→7→8; по одному снимаемому buff на цель.
- Единица результата: максимум отдельных целей
- Совместное действие: Структурная броня [G02](../../10_ProgressionGates.md#G02) и расовая черта не dispellable. Не заменяет [R_GATE02](R_GATE02.md).
- Сумма прямых цен: 31 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 59 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 30 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 28 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU).
- Для производства указанных в цене слитков дополнительно потребуется: 682 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 2 380 [Уголь (COAL)](../08_Resources.md#COAL) + 1 888 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 1 200 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 336 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU); 2 сут 21 ч 32 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Все покупки этой ветки мгновенные после оплаты. Время накопления ресурсов, производства слитков и выполнения требований считается отдельно.
