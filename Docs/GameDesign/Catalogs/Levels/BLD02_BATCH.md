# BLD02_BATCH — Кузница: ёмкость одного заказа

Предложенный каталог для обсуждения. Таблица раскрыта из индивидуально заданных цен и интервалов; это не проверенный игровой баланс.

- Уровней: **4**. Уровень здесь — номер покупки этой ветки; итоговый ранг/слот уточняется эффектом.
- Доступ: [G02](../../10_ProgressionGates.md#G02); после MVP
- Назначение: Меньше ручных одинаковых заказов
- Эффект: Один заказ включает до 12, 36, 120, 240 слитков вместо начальных 4. Оплачивается каждая единица; длина очереди остаётся отдельным ограничением. Несколько небольших заказов можно поставить в ту же очередь.
- Единица результата: слитки в одном заказе
- Совместное действие: Абсолютный предел размера партии; скорость и выход рецепта не изменяются. Вход партии считается ceil(n × base × (1 − saving)) отдельно для RAW и [Уголь (COAL)](../08_Resources.md#COAL); выход ровно n. Неизменяемые входные доли единиц задаются разностью округлённых префиксов. Отмена возвращает только записанные доли ещё не начатого суффикса, без пересчёта по новому рецепту или скидке; обработка по порядку, выборочная отмена долей запрещена.
- Сумма прямых цен: 12 [Медный слиток (INGOT_CU)](../08_Resources.md#INGOT_CU) + 98 [Железный слиток (INGOT_FE)](../08_Resources.md#INGOT_FE) + 45 [Серебряный слиток (INGOT_AG)](../08_Resources.md#INGOT_AG) + 12 [Золотой слиток (INGOT_AU)](../08_Resources.md#INGOT_AU) + 40 [Мифрильный слиток (INGOT_MY)](../08_Resources.md#INGOT_MY) + 12 [Обработанный астралит (INGOT_AS)](../08_Resources.md#INGOT_AS).
- Для производства указанных в цене слитков дополнительно потребуется: 144 [Медная руда (RAW_CU)](../08_Resources.md#RAW_CU) + 4 958 [Уголь (COAL)](../08_Resources.md#COAL) + 2 156 [Железная руда (RAW_FE)](../08_Resources.md#RAW_FE) + 1 440 [Серебряная руда (RAW_AG)](../08_Resources.md#RAW_AG) + 480 [Золотая руда (RAW_AU)](../08_Resources.md#RAW_AU) + 2 400 [Мифрильная руда (RAW_MY)](../08_Resources.md#RAW_MY) + 1 080 [Астралит (RAW_AS)](../08_Resources.md#RAW_AS); 9 сут 14 ч 34 мин работы одной печи ×1 по базовым рецептам. Это расшифровка производства, а не повторная оплата слитков.
- Сумма работы этой последовательной ветки: 16 ч 15 мин при скорости ×1. Материалы prerequisites и время кузницы считаются отдельно.
