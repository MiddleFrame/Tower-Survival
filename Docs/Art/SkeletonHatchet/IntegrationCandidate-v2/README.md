## Бег без хромоты

PixelLab не смог получить равный двухшаговый цикл одним запросом и дважды переносил короткий шаг с одной ноги на другую. В v2 используются две явно противоположные контактные позы. Вторая получена точным зеркалированием только ног относительно центра таза; верх тела, низкая свободная рука и топор не зеркалировались. PixelLab рассчитал один переход между контактами, затем обратная половина цикла собрана из тех же кадров в обратном порядке.

Пары `frame-01`/`frame-07`, `frame-02`/`frame-06` и `frame-03`/`frame-05` побайтно одинаковы. Поэтому обе ноги проходят одинаковый переход в противоположные половины цикла. `symmetry-qa.json` фиксирует порядок сборки. Нижняя точка меняется только на один пиксель.

## Общие замечания

`candidate-qa.json` подтверждает размеры, число кадров, замыкание, жёсткую альфу, отсутствие касаний границы и нижнюю точку. Тени не запечены. Атаки используют 128×128 только как прозрачное место для замаха; исходный персонаж не уменьшался.

Перед интеграцией импортировать только `frame-*.png` без последнего контрольного дубля, сохранить единый PPU и point filtering. Для атак перенести единственное событие урона на фактический контакт. Масштаб, pivot и отступы окончательно оценить в игре, как ранее договорились.

Сырые результаты, отклонённые варианты и происхождение лежат в `../AnimationTrials/`.
