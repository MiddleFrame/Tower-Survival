# Skeletor / Pixelorama: реальный запуск

28.10.2026. Проверен ещё один из ранее не запущенных вариантов. Это эксперимент, а не утверждённые игровые анимации. Игровые ассеты и настройки Unity не менялись.

## Результаты

- `skeletor-walk-comparison.gif` и `skeletor-attack-comparison.gif`: рядом показаны CleanEdge, OmniScale и NNS.
- `walk-*.gif`, `attack-*.gif`: отдельные анимации, по 12 кадров.
- `skeleton-skeletor-trials.pxo`: настоящий проект Pixelorama с группами костей, слоями деталей, позами и метаданными Skeletor, 73 кадра включая нейтральную контрольную позу.
- `unposed-baseline.png`: контроль без преобразований. Его видимые RGBA-пиксели точно совпадают с утверждённым исходником, смещённым на (32,32) в холсте 160×160.

Для движения использовались реальные `SkeletonBone`, `IKAlgorithms.FABRIK`, `BoneManager.generate_pose` и шейдеры расширения. Это не повторный запуск рендера JatCool под другим названием. Части выделены из исходных пикселей по сохранённой карте сегментации; новые поверхности костей не дорисовывались. Цепочки рук и ног связаны иерархией, стопы задаются целями IK, верх тела движется вместе с головой и руками.

Результат не решил художественную проблему: на сгибах сохраняются изломы, исходных поверхностей для больших поворотов не хватает, исходная сегментация ограничивает качество. Один работающий IK и более аккуратный поворот пикселей не гарантируют хорошую анимацию. Все кадры просмотрены в контактных листах при нативном масштабе и увеличении. Проверки — в `qa.json`; сохранение PNG и проекта — в `runtime-report.json`.

## Среда и воспроизводимость

[Skeletor](https://github.com/Variable-Interactive/Skeletor) 0.19, API 10, ревизия `984b990fd9d6384fc9a76057f917bd579326cc00`. [Pixelorama](https://github.com/Orama-Interactive/Pixelorama) из клона текущего исходного кода, версия приложения `v1.2.4-rc2`; Godot 4.7.2, OpenGL Compatibility, реальный GPU-рендер. Не является тестом стабильного релиза Pixelorama.

Внешняя рабочая копия: `C:/Users/tente/AppData/Local/Temp/lone-tower-animation-lab-20261028/pixelorama-source`. В ней добавлены расширение и драйвер `lab_driver.gd`, отдельный каталог пользовательских настроек и фоновое окно за пределами экрана. Драйвер сохранён также рядом с этим README. Глобальное подключение MCP не менялось, существующие окна приложений не управлялись.

PNG и PXO экспортированы. При закрытии этого изолированного процесса Godot сообщает о неосвобождённых GPU-ресурсах; чистое завершение и пригодность инструмента для постоянного использования не заявляются. Полные журналы сохранены во внешнем рабочем каталоге (`skeletor-final*.log`). Ранние журналы также содержат ошибки от первичной регистрации UI/ресурсов; они не использованы как доказательство качества.

## Дополнительная проверка Sprite Sheet Diffusion

В `ModelTraining/pretrained_model/download_animateanyone.sh` найден указатель на базовый PoseGuider patrolli. Файл скачан и проверен: его ключи `conv_in`, `blocks`, `conv_out` соответствуют другой архитектуре, тогда как выбранный в SSD класс ожидает `conv_layers`, несколько уровней и cross-attention. Эта замена не выполнена.

Другой скрипт авторов (`download.sh`) содержит ссылку на PoseGuider AniPortrait размером 670182863 байта. Это дополнительная зацепка, которая ещё не проверена загрузкой в выбранную архитектуру; отсутствие веса в Drive-папке не доказывает, что совместимый комплект нельзя собрать. Полный инференс SSD в этом эксперименте не запускался.
