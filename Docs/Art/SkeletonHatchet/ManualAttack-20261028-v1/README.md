## Как сделано

Работа выполнена через Aseprite MCP на новой копии, с невидимым слоем Reference. Рука в новых положениях нарисована сетками пикселей; в восстановлении использована часть исходного предплечья. Череп, грудная клетка, свободная рука и ноги взяты из утверждённого спрайта. Верх тела перемещается на несколько пикселей относительно неподвижного таза и стоп.

Нарисованная сначала новая железная часть топора меняла размер, поэтому в итоговом варианте используется исходная деталь. В фазе удара она повёрнута на 90° с сохранением пикселей. Рукоять и соединения кисти отредактированы отдельно. Нейросетевые промежуточные кадры, растяжение изображения и сглаживание не применялись.

Кадры: исходная стойка → начало подъёма → поднятая рука → перенос вперёд → удар → доведение → восстановление → исходная стойка. Длительности: 240, 100, 160, 40, 60, 100, 120, 240 мс. Цикл 1060 мс.

## Проверка и ограничения

Все восемь поз просмотрены через Aseprite MCP при 1× и целочисленном увеличении. Исправлены размер топора, соединение локтя и недостаточный запас холста справа.

`package_preview.py` только разрезает экспорт Aseprite, проверяет пиксели и упаковывает GIF. Он не рисует кадры. В `qa.json` проверены точное совпадение видимых пикселей первой/последней стойки с исходником, одинаковые стопы во всех кадрах, бинарная прозрачность, отсутствие обрезанных краями пикселей и длительности GIF. Цвета остаются в исходной палитре.

Это черновик: рисунок новых частей руки проще исходного, движение корпуса ограничено переносом, поворот торса и выразительная работа таза не разработаны. Технические проверки не означают художественное принятие. В Unity, Game View и на Android вариант не проверялся; игровые файлы не менялись.
