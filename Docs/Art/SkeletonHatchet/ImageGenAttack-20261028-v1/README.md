# ImageGen: ещё одна проба атаки

Эксперимент, не утверждённый игровой ассет. В Unity не импортирован. Исходный утверждённый спрайт не менялся.

Генерация: встроенный ImageGen, исходный `../skeleton-hatchet-approved-96.png` передан как референс персонажа, палитры и низкого ракурса 3/4 вправо. Полные запросы находятся в `prompts.txt`.

Первый запрос создавал единый лист из 8 последовательных поз. Во втором запросе исправлялась только поза замаха, в которой поменялись местами руки. Из второго результата взята только третья ячейка; остальные кадры берутся из первого результата. Оба полных PNG сохранены.

Модель вернула **1774×887 вместо запрошенных 512×256**. Это не генерация нативных кадров 128×128. В исходнике есть сглаживание, полутона прозрачности и отклонения от внешности эталона.

## GIF

- `hatchet-imagegen-attack-trial.aseprite` — редактируемая копия, импортированная и просмотренная через Aseprite MCP; прозрачные PNG — в `native-frames/`.

В выбранном цикле используются исходные ячейки 1, 2, 3, 5, 6, 7, 1. Ячейка 4 исключена из-за обрезанного краем листа топора. Возврат использует целиком первую позу; неподвижный череп поверх остальных кадров не вклеивался.

## Обработка и проверка

`package_trial.py` разрезает регулярный лист, выравнивает всю ячейку по нижней линии стоп, вызывает бесплатный открытый [Retro Diffusion Pixel Art Fixer](https://github.com/Retro-Diffusion/pixel-art-fixer) с фиксированным шагом 4, приводит цвета к палитре исходного спрайта, убирает отдельные островки размером до двух пикселей и пакует GIF. Новые позы кодом не рисуются. Альфа итоговых кадров бинарная; прозрачный RGB обнулён.

Все семь кадров просмотрены при 1× и 3×, в том числе на пурпурном фоне. Движение, контуры стоп, череп и рука остаются пробными: выравнивание линии пола не делает стопы или анатомию одинаковыми. Изменения лица, оружия и пропорций по сравнению с эталоном не устранены автоматически. Не считать эти технические проверки художественным принятием.

Источник генерации сохранён отдельно от обработанного результата; в `qa.json` записаны реальные размеры, выбор кадров и смещения. Сохранённые оригиналы ImageGen также остаются в `C:/Users/tente/.codex/generated_images/01a10da3-9ac6-78f0-94e8-c541e0bf8f31/`.
