## Что получилось

Встроенный ImageGen получил эталон `../../SkeletonHatchet/skeleton-hatchet-approved-96.png` и запрос на спрайт с логической сеткой 96×96, увеличенный nearest-neighbor в 12 раз. Вместо запрошенных 1152×1152 он вернул 1254×1254 RGB. Фон был специально задан однотонным пурпурным для последующего удаления.

Рисунок приблизительно следует ожидаемой сетке, но исходник не является точным увеличением 96×96: шаги и оттенки местами отклоняются. Скрипт `prepare.py` берёт медианный цвет центрального участка каждой ячейки сетки 96×96 и удаляет пурпурный фон. Это реконструкция маленького спрайта с потерями, а не обратимое сжатие исходного изображения.

Для ограничения палитры цвета сначала разделены по цветовым признакам на группы контура, ткани, костей, дерева и кристалла; каждая группа сокращена отдельно без дизеринга. Это эвристика по цвету, а не полноценная разметка материалов. Результат содержит 19 непрозрачных цветов. `skeleton-mage-sampled-96.png` сохраняет этап до сокращения палитры.

Ручных правок анатомии, глазниц и отдельных пикселей в этой пробе нет. Дальняя глазница остаётся узкой; череп под капюшоном меньше, чем у эталона. Художественная приемлемость ещё не утверждена.

## Проверка

Итоговый файл: 96×96 RGBA, альфа только 0/255; RGB прозрачных пикселей обнулён. Пурпурный фон отсутствует. Бирюзовые цвета по проверке расположены только в области кристалла. Видимая область: x=23..81, y=5..92, то есть 59×88 пикселей. Превью увеличены nearest-neighbor; отдельно осмотрены 1:1 и четыре сплошных фона.

В исходном C2PA-блоке `softwareAgent` указаны `name: gpt-image`, `version: 2.0`. Это содержимое метаданных файла, не подтверждённый идентификатор серверной модели; криптографическая подпись C2PA не проверялась. Ответ инструмента не раскрывает модель. Переход на Image 2.5 по этой пробе не подтверждён.

Повторить обработку: `python prepare.py` (Pillow и NumPy). Исходник и итог хранятся отдельно. При будущем импорте использовать Sprite / Single, Point, mipmaps off, compression None и PPU по соседним игровым кадрам. Unity, атлас и Android в этой задаче не проверялись.
