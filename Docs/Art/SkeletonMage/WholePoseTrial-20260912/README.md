# Цельные позы ожидания — художественная проба

После отказа от статичной перекладки проверяется один цикл, полностью нарисованный ImageGen: шесть поз в листе 3×2. Запрос `prompt.txt`, исходник `idle-whole-pose-source.png` (1536×1024 RGB). Генерация выполнена встроенным ImageGen с исходным магом в качестве референса, на сплошном пурпурном фоне. Это не новая универсальная технология и не доказательство решения временной согласованности.

`prepare.py` удаляет фон, берёт фиксированную сетку 96×96 на ячейку, сводит цвета к общей исходной палитре и выравнивает кадры только целочисленным переносом всей фигуры по опорной стопе. Кости и строки не изгибаются, отдельные части не вращаются, области изображения не замораживаются. Палитра кристалла допускается только около навершия посоха, чтобы тёмно-синие края тела не стали бирюзовыми.

Открыть `preview.html` для сравнения с предыдущей перекладкой. `Previews/idle.gif` — самостоятельный просмотр нового цикла, `Previews/contact.png` — шесть исходных поз. `idle-whole-pose-atlas.png` — прозрачный атлас, `Frames/` — отдельные PNG. После замечания о слишком сильном наклоне третья исходная поза исключена из проигрывания: индексы 0, 1, 3, 4, 5, длительности 200, 180, 180, 220, 200 мс. Этот порядок указан в `manifest.json`. Исходные изображения сохранены; прежний GIF — `Previews/idle-before-bend-fix.gif`.

Изменение позы затрагивает таз, колени, рёбра и ткань. Проверка контактного листа не доказывает плавность проигрывания: рисунок между кадрами по-прежнему меняется. Статистика изменённых RGBA-позиций в `qa.json` включает полезное движение и не является измерением чистого мерцания. Эту пробу нужно оценить художественно; она не заменяет весь комплект анимаций.

Пересборка: `python prepare.py` с Pillow и NumPy. Старые пробы и исходный маг сохранены. Unity не менялась и не проверялась.
