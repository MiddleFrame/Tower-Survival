# Проба анимации из закреплённых частей

2026-09-12. Выполнен согласованный первый этап проверки способа: боковое
ожидание (8 кадров), ходьба (8 кадров), короткий каст рукой (10 кадров).
Остальные атаки, ракурсы и духи сохраняются в `../StableAnimationWorkflow.md`
и в эту контрольную пробу не входят.

Это анимация существующего изображения, а не новая генерация ImageGen.
Все части вырезаны из понравившегося мастера 96×96, который не изменялся.
Новые скрытые детали или открытая ладонь не дорисовывались. `Parts/` содержит
маскированные PNG с исходными пикселями. `build_trial.py` собирает движение.

## Что изменилось

- Череп, глаза и капюшон в ожидании и касте совпадают с мастером побитово.
- В ожидании стопы и посох неподвижны. Корпус сдвигается на один пиксель,
  свободная рука — на один пиксель, нижняя ткань двигается ограниченным циклом.
- Кости ног и свободной руки имеют фиксированные длины в расчёте суставов.
  Растяжение для достижения цели запрещено. Кисть поворачивается с предплечьем.
- Ходьба содержит перенос обеих стоп с подъёмом не более трёх пикселей,
  корпус смещается на один пиксель между фазами. Проверены контактные листы,
  но естественность и ощущение шага требуют пользовательской оценки в движении.
- Повороты используют ближайший пиксель исходника. Палитра остаётся исходной,
  однако ступеньки повернутого контура могут меняться; это не обещание полного
  постоянства всех экранных пикселей во время вращения.
- Стыки закрываются маленькими копиями исходных суставов. Изолированные
  компоненты до трёх пикселей после сборки удаляются с записью количества в QA.

## Файлы

- `Atlases/` — PNG RGBA с реальной прозрачностью, кадры 128×128. Исходный
  персонаж не увеличен: вокруг исходных 96×96 добавлено по 16 пикселей поля.
- `Frames/` — 26 отдельных кадров; `manifest.json` — порядок и длительность.
- `Previews/three-clips.gif` — три клипа рядом (общий шаг превью 100 мс).
- `Previews/idle-before-after.gif` — старое и новое ожидание при 140 мс на кадр.
- `Previews/idle.gif`, `walk.gif`, `cast.gif` — отдельные увеличенные GIF.
  В них серый фон только для просмотра; у игровых PNG фон прозрачный.
- `preview.html` и `viewer-data.js` — просмотрщик с паузой, шагом, скоростью,
  масштабом и сменой фона. Открывать HTML вместе с JS из этой папки.
- `rig-qa.json` — проверка частей и геометрии. Счётчик изменённых пикселей
  включает намеренное движение и не является чистой мерой мерцания текстуры.

## Проверки и ограничения

Без трансформаций все части собираются в исходный мастер без единого отличия.
Проверены сохранение головы, стоп/посоха в ожидании, исходная палитра,
бинарный alpha, отсутствие обрезки по краям, фиксированные длины костей.

Видимая слабость метода — механический характер движения, ступеньки после
поворотов, возможные стыки частей. В касте использована прежняя кисть,
а не отдельная выразительная открытая ладонь. Движение короткое, в пределах
длины исходной руки. Свет, снаряд и духи в эту пробу не добавлялись.

Просмотрены все позы на контактных листах. HTML имеет проверку синтаксиса,
но интерактивное проигрывание через встроенный браузер не проверялось.
В Unity ничего не импортировано; сцены, prefab, GUID и исходные спрайты
не менялись. Это кандидат для оценки, не принятый игровой комплект.
