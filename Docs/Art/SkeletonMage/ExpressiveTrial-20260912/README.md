# Скелет-маг: подвижная проба

Откройте `preview.html`. Слева обычное ожидание, по центру ходьба, справа вход в каст → удержание заданной длительности → выпуск → выход. Ниже можно остановить и рассмотреть любой кадр. Подложка однотонная и переключается; PNG имеют настоящую прозрачность.

## Изменения

- Корпус и таз в ожидании движутся в общем непрерывном поле смещения, которое затухает к стопам. Между независимо сдвинутыми половинами тела больше нет горизонтального разреза. Голова слегка поворачивается, свободная рука качается.
- Плащ и набедренная ткань колышутся, их прикреплённые края остаются на месте относительно корпуса. Это деформация неизменного рисунка, без генерации новой текстуры каждого кадра.
- В ходьбе чередуются опорная и переносимая ноги; подъём цели стопы ограничен тремя пикселями. Положение коленей вычисляется с постоянными длинами костей. Низкое разрешение и поворот вырезанных деталей всё ещё ограничивают гладкость суставов.
- Для каста через ImageGen получена новая опорная поза с открытой ладонью перед корпусом. Посох в этой позе находится позади тела. Нужен отдельный переход из обычной походной позы с посохом спереди; здесь он ещё не реализован.
- `cast-hold` — самостоятельный цикл из 12 кадров. Время удержания задаётся внешним таймером. Для каждого его кадра есть совместимый вариант выпуска, первый кадр которого точно совпадает с текущей удерживаемой позой. Все варианты сходятся в общую позу выхода.

## Файлы и порядок

`Atlases/` — прозрачные листы с ячейкой 128 × 128, четыре столбца, порядок слева направо и сверху вниз. Пустые ячейки последней строки не входят в анимацию; количество кадров указано в `manifest.json`.

Основные анимации: `idle`, `walk`, `cast-ready`, `cast-enter`, `cast-hold`, `cast-release`, `cast-exit`. `cast-release-from-00` … `cast-release-from-11` — варианты выпуска для соответствующих кадров удержания, а не новые типы атаки.

Жизненный цикл: готовность → вход → повторять удержание до команды → выбрать выпуск по текущему индексу удержания → выход → готовность. Событие снаряда приходится на индекс 2 выпуска, то есть третий кадр. Снаряд, свечение и другие эффекты не запечены в персонажа.

`Frames/` содержит отдельные PNG. `Previews/` — GIF на однотонном сером фоне и контактные листы. Серый фон есть только в превью. `cast-demo-1s.gif` и `cast-demo-3s.gif` показывают разные длительности удержания.

## Происхождение и воспроизведение

Обычное ожидание и ходьба используют неизменённый исходник `../UpdateTrial-20260909/skeleton-mage-idle-96.png`. Его SHA-256: `e96cbf79b24eb270f3dbccb1688ca7e598dedc21c3fc358081aef32ddde247b3`.

Новый исходник каста сохранён в `Sources/cast-hold-key-source.png`, запрос — в `Prompts/cast-hold-key.txt`. Генератор вернул RGB 1254 × 1254 с нарисованными серыми клетками вопреки запросу прозрачности. Они удалены по ахроматическому цвету; изображение сведено к сетке 108 × 108, к общей палитре исходного мага и помещено в ячейку 128 × 128. Готовый обработанный ключ — `cast-key-128.png`. Это результат обработки крупного изображения, не нативная генерация в 128 × 128.

По новой договорённости следующие генерации должны запрашивать только сплошной контрастный фон, например #FF00FF, с последующим удалением. Не запрашивать клетчатый фон или рисованную имитацию прозрачности.

Для пересборки из сохранённых ключей: `python build_v2.py` (Pillow и NumPy). `rig_base.py` содержит маски исходного персонажа и преобразования деталей. Каждый кадр повторно берёт цвета исходной текстуры, без сглаживания и промежуточного растрового накопления. Удаление отделившихся компонентов размером до трёх пикселей отражено в `qa.json`.

## Проверено и ограничения

Проверены бинарная альфа, единая палитра, размер ячеек, отсутствие касания краёв кадра, неизменность исходного мага, точное совпадение всех 12 переходов удержание → выпуск и выпуск → выход. Ключевые анимации просмотрены на контактных листах; художественную естественность движения ещё нужно оценить в проигрывании.

HTML проверен статически и проверкой JavaScript; проверка в браузере не выполнена. В Unity ничего не импортировано, сцены и исходные игровые ресурсы не изменялись. Остальные направления, атаки посохом, двухручный ритуал и эффекты душ в эту пробу не входят.
