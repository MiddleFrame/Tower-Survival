# Боковая атака — первая нативная проба Aseprite

Дата: 05.10.2026. Статус: черновик для визуальной оценки, не утверждён и не интегрирован.

Исходник: `../../Base-v1/armored-skeleton-128.png`. Создан новый документ через Aseprite MCP; PixelLab и ImageGen не использовались. Исходный PNG сохранён без изменений, SHA-256 до/после проверки совпадает (`qa.json`).

В документе 9 кадров 128×128, цикл 990 мс. Скрытый слой Reference хранит исходную стойку; отдельно редактируются корпус со шлемом, рука, топор с хватом. Фазы: стойка → подготовка → подъём → замах → удар → контакт → доведение → возврат → стойка. Рука перепозирована нативными пиксельными правками, исходный топор повёрнут на пиксельной сетке без сглаживания. Корпус и шлем смещаются совместно, лицо не ретушировано поверх чужой анимации. Стопы стоят на месте.

Покадрово просмотрены все 9 кадров в 1x и nearest-neighbor увеличении. Первый и последний кадры точно совпадают с исходником; область стоп и область глазниц после компенсации движения корпуса неизменны во всех кадрах. Все непрозрачные пиксели внутри холста, минимальный правый запас 5 пикселей. Параметры поз, длительности и границы записаны в `qa.json`.

Это технические и покадровые проверки, не художественное принятие движения. Рука пока выглядит жёсткой, вращение топора местами ступенчатое; корпус почти не разворачивается, лишь смещается. Не объявлять пробу готовой атакой. До продвижения нужны оценка GIF пользователем и, при интеграции, отдельная проверка в реальном масштабе игры.

Для просмотра: `side-attack-1x.gif`, `side-attack-3x.gif`, `side-attack-frames-1x.png`, `side-attack-frames-3x.png`. Редактируемый источник: `armored-skeleton-side-attack.aseprite`. Увеличенный `.aseprite` — только экспортная копия для просмотра. `side-attack-sheet.png` и JSON содержат 9 неизрезанных ячеек 128×128 в исходном порядке и их длительности.

Unity-ассеты, префабы, сцены и release notes не изменены. Качество в игре и Play Mode не проверялись; коммит не создавался.
